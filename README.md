# Diplomski rad

## Analiza faktora koji utiču na prihvatanje korišćenja sistema baziranih na veštačkoj inteligenciji u zdravstvu

Ovaj repozitorijum sadrži programski kod i vizualizacije korišćene za analizu podataka u okviru diplomskog rada.

## Sadržaj repozitorijuma

### Python analiza
Jupyter Notebook sadrži kompletnu statističku analizu podataka, uključujući:

- pripremu i obradu podataka
- formiranje tematskih skorova
- proveru pouzdanosti tematskih skorova primenom Cronbach alpha koeficijenta
- deskriptivnu statistiku
- Spearmanovu korelacionu analizu
- hijerarhijsku regresionu analizu
- proveru pretpostavki regresionog modela
- Random Forest regresiju
- klasifikacione modele
- procenu prediktivne važnosti analiziranih faktora

### Power BI
Power BI fajl sadrži interaktivne vizualizacije rezultata istraživanja i karakteristika uzorka.

## Podaci

Analiza je sprovedena na podacima prikupljenim putem ankete. Istraživanje je obuhvatilo 121 ispitanika.
